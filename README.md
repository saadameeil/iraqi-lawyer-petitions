# منصة تحرير وطباعة العرائض القضائية العراقية ⚖️
### المحامي سعد فراس أميل

تطبيق ويب تقدمي (PWA) مخصص لهواتف الآيفون ومتصفح Safari لصياغة وطباعة عرائض الدعاوى والشكاوى الجزائية وفق أصول وقواعد المحاكم العراقية.

---

## 📁 هيكلية المشروع (Project Structure)
- `index.html`: الصفحة الرئيسية وواجهة التحرير والمعاينة الحية لورقة A4.
- `style.css`: التنسيقات وتصميم ورقة الـ A4 ومحرك الطباعة (`@media print`) وخط النظام الرسمي للآيفون (SF Arabic).
- `app.js`: المحرك البرمجي، التحليل الذكي لنصوص الذكاء الاصطناعي (AI Parser)، الأرشيف المحلي (LocalStorage)، ومحرك الملاءمة لصفحة واحدة (Auto-fit).
- `manifest.json`: إعدادات تثبيت التطبيق كـ PWA على شاشة الآيفون.
- `apple-touch-icon.png`: أيقونة التطبيق الرسمية (الميزان الذهبي).
- `generate_icons.py`: سكربت توليد الأيقونات بدقة عالية.

---

## 🚀 تشغيل التطبيق محلياً (Local Run)
لتشغيل السيرفر المحلي عبر منفذ 8080:
```bash
python -m http.server 8080 --directory "C:\Users\saad7\.gemini\antigravity\scratch\iraqi_lawyer_petitions"
```

ولبثه عبر رابط إنترنت مشفر للآيفون (Cloudflare Tunnel):
```bash
cloudflared tunnel --url http://127.0.0.1:8080
```

## ⚖️ معايير التنسيق المعتمدة
1. **استغلال مساحة ورقة A4 كاملة**: دون بسملة، مع تصدير جهة التوجيه لأعلى نقطة.
2. **عبارة التقدير والاحترام**: تتوسط الورقة مباشرة بعد انتهاء نص العريضة والطلبات.
3. **التاريخ**: يظهر بصيغة رقمية أصولية (`D / M / YYYY`) بدون حرف "م".
4. **تذييل التوقيع**: في أسفل الورقة بالطرف، مرتب عمودياً (الصفة، ثم الاسم تحته، ثم مساحة بيضاء صافية للتوقيع بالقلم).
